# Contributing to Nightpost

Thank you for considering a contribution. Two things you should know up front.

## Licence

The server in this repository is AGPL-3.0 (see LICENSE and NOTICE). The
producer packages (nightpost/laravel, @nightpost/*) are MIT. The managed
control plane is a separate product and is not part of this repository.

## DCO: sign every commit

This project accepts contributions under the Developer Certificate of Origin
(DCO, http://developercertificate.org). Every commit must carry a sign-off
line proving you have the right to submit the patch under AGPL-3.0:

    Signed-off-by: Your Name <you@example.com>

Add it with git commit --signoff (or -s). Commits without a sign-off cannot
be merged.

Why DCO and not a CLA: DCO keeps the contribution flow friction-free and
documents provenance. It also means inbound=outbound permanently — a future
relicence (e.g. to BUSL) would need every contributor's consent. That is a
deliberate trade recorded in LICENSING.md ("Alternatives considered"); the
decision window for a CLA closes with the first outside patch.
