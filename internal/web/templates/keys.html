Ingest keys

Per-project bearer keys for every ingest route. A project without a key still accepts unsigned (legacy) traffic; rotating or revoking takes effect immediately — update the producer env in the same window. Revoking drops the project back to unsigned (legacy) admission.

The Browser origin column is the allowlist for in-page reporters (the profile/error routes). Leave it empty to inherit the install default set by -cors-origin; a wildcard is refused, because these routes accept unauthenticated browser posts.
